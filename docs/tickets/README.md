# Tickets

Eine Datei pro Ticket. Die Nummer entspricht der Reihenfolge der Umsetzung (01 bis 10 und 14 bilden v0.1, 00 und 11 bis 13 laufen daneben; 14 kommt vor 10). Jedes Ticket nennt Ziel, Akzeptanzkriterien, Designprinzip, Branch und Status (`offen`, `in Arbeit`, `erledigt`). Den Status ändert, wer das Ticket bearbeitet, im selben Branch.
